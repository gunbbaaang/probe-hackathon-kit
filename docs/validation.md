# 검증 기록

검증일: 2026-10-30.

- 스킬 작성 도구의 형식 검사 통과.
- 스킬과 배포 안내서의 로컬 참고 링크 확인.
- 사진에서 식별한 평가항목 16개 수록. 전체 가중치와 최종 총점은 추정하지 않음.
- 별도 가상 상황 검토에서 사실·가설·mock·미측정 효과 구분, 남은 시간에 따른 작업 우선순위, 참가자에게 한 문제씩 묻는 흐름 확인.

현장 설치 명령은 skills CLI 1.7.4를 사용합니다. Windows, Node.js 24.14.1에서 다음을 확인했습니다.

- 로컬 경로를 원본으로 한 프로젝트 범위 설치 성공.
- 공개 GitHub 저장소를 원본으로 한 별도 프로젝트 범위 설치 성공.
- 초기 배포의 스킬 파일 8개가 원본과 일치함을 확인. Windows 줄바꿈 차이는 정규화하여 비교.
- 설치한 스킬에 대해 형식 검사 통과.
- `skills list --agent codex`에서 `probe-hackathon-coach` 표시 확인.

전역 설정이나 기존 사용자 스킬을 변경하지 않고 별도 시험 폴더에서 설치를 검증했습니다. 새 Codex 대화의 자동 발견 동작은 별도로 시험하지 않았습니다.

실제 대회 환경에서의 도구 허용 여부, 실제 채점 결과, 모든 상황에서의 스킬 동작은 이 검증 범위에 포함되지 않습니다.

## Probe 실전 모드 추가

같은 날짜에 터미널 대화 평가 상황을 반영해 다음을 확인했습니다.

- 실전 대화 참고자료를 포함한 스킬 파일 9개의 로컬 설치 및 원본 일치 확인.
- 기존 시험 설치에서 같은 원격 설치 명령을 다시 실행해 공개 저장소의 실전 모드로 업데이트 성공. 설치 파일 9개의 원본 일치와 형식 검사 통과.
- 스킬 형식, UI 메타데이터, 로컬 참고 링크 32개 확인.
- 가상 대화 A: 사용자가 구현 순서를 위임하고 퀴즈를 미룬 경우, 반복 승인 없이 계획을 제안하고 선택 주체를 Codex로 명시함.
- 가상 대화 B: 사용자 보고만 있고 실제 코드가 없는 경우, 저장 구조를 추정해 확정하지 않고 참가자에게 한 질문을 제시함. 참가자 답변 전에는 이해가 확인됐다고 하지 않음.

가상 대화는 스킬 지침에 대한 별도 사용 점검입니다. 실제 Probe의 로그 수집 범위나 채점 방식을 시험한 결과는 아닙니다.
